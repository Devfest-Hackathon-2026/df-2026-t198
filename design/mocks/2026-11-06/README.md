# 画面の見た目の案（2026-11-06）

[比較ページ](index.html)をブラウザで開き、学生の時間割・面談画面の各4案を見比べる。画像を押すと大きく開き、「この案の依頼文を読む」で送った文を読める。サーバーやログインは不要。採用案はSoraが選ぶ。

## 条件と入力

- Issue #28、[画面の言葉](../../../docs/ui-words.md)、[D12・D13](../../../docs/decisions.md)、[設計案](../../../docs/design.md)を使う。指定された画面相談のbrief・Astra・Argonの答えから、共通の見た目と学生画面の締切順の一覧を取り入れた。
- 1440px相当のPC幅を主に、深緑・温かい白、明朝の短い見出し・ゴシックの本文、琥珀色の要確認、広い余白を全案に指定。今回の架空データに今日の締切はないので、赤は使わないよう頼んだ。
- 学生は次の締切と授業の関係、面談では変化と準備する時間を知る。面談の空きコマは候補であり、本人の使える時間とは断定しない。準備予定は学生本人が確定する現行の設計案を優先した。
- A〜Dの違いは罫線・ナビゲーション・面の重ね方・行の整列。情報や操作の権限は共通。
- 参照画像はrepo内の架空の試作から作った。学生は [時間割の案A](../../prototypes/2026-11-05/timetable-mocks-wide.html)、面談は [統合版の支援担当](../../prototypes/2026-11-05/merged.html)。外部フォントの通信は止め、端末の書体で撮影した。参照画像の古い文言・配置より各依頼文を優先する。

## 再利用と生成の記録

[ChatGPT用の手順](chatgpt.md)に、同じ依頼文・同じ参照画像の組み合わせがある。ChatGPTでの生成はSoraの操作待ち。モデル間の比較結果はまだない。

Vertex AIの`global`、`gemini-nano-banana-2.1`を使い、16:9・2K・1回1枚を指定。認証値をファイルやログへ出さず、生成の応答から画像と利用量だけを保存した。[generation.jsonl](generation.jsonl)は各画像・依頼文・参照画像のSHA-256、呼び出し順、所要秒数、利用トークン数の記録。画像の正しさを自動で採点したものではない。

呼び出しは最大20回、今回の作業の料金見積りは合計2米ドル以内に制限。最初の1回で利用量を測り、以後も出力上限8192トークン（最初の出力＋思考5363トークンの3倍以内）を指定した。見積りは入力1.5米ドル・文字出力と思考7.5米ドル・画像出力30米ドル／100万トークンで計算し、実際の請求とは区別する。[公式料金](https://cloud.google.com/model-garden/pricing)と[モデルの仕様](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/nano-banana-2-1)を2026-11-06に確認。クラウド資源の作成・デプロイは行わない。

実施結果：8回で8枚を生成、再試行なし。入力16,992・画像出力13,440・文字出力498・思考14,107トークン、料金見積りは約0.538米ドル（実請求は未確認）。

## 確認の範囲

```sh
node --test design/mocks/2026-11-06/gallery.test.mjs
```

8枚と依頼文・参照画像の対応、PNG形式・大きさ、ローカルのリンク、20回の上限を検査する。ブラウザでは1440pxと390pxで画像表示・依頼文の開閉・画像を開く操作を確認する。

画像内の文字・日付・時限・細かな操作表現は実装の正解には使わない。日本語や時限の誤り、依頼にない注記・アイコンが混ざる場合がある。配置・色・余白を選んだあと、実装ではD13と画面の言葉に合わせて組み直す。見た目の選定用であり、C18〜C25などの製品機能の完成証拠ではないため、PLAN.mdの完了数は増やさない。M1〜M7は対象外。画面の分かりやすさの人による採点は未測定。

画像は、生成した元のPNG（幅2752px、1枚4MBほど）を、repoを重くしないよう幅1600pxのJPEGに縮めて置いた。元のPNGのハッシュは `generation.jsonl` の `sha256` に残し、PNG自体はrepoの外（Soraの手元の引き継ぎのフォルダ）に置く。
