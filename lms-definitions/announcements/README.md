承認された既存プロジェクトとADCで実行する（認証・API有効化・リソース作成はこのコマンドでは行わない）。

```sh

# 普段の確認は24件だけ（確認用の消費を避ける）

```

既定は30件。確認用を含む評価は日本時間で1日1回（失敗した回も含む）。同じプロジェクトで同時に評価しない。回数・トークン数・推定費用は標準出力、日次の費用予約と初回測定値は `~/.cache/kadai-hisho/m3/<project>/usage.json` に保存する。本文・引用・生の応答・SDKの例外は保存しない。途中の中断では予約を残す。ロックが残った場合は、実行中のプロセスがないことを人が確認してから対処する。記録を消して上限を回避しない。

初回30件が最後まで済むと、実測トークン数・呼び出し回数を基準に固定し、その後は各3倍まで。初回は30回・合計60万トークンの上限。呼び出しごとに入力のUTF-8バイト数＋指示・schema・1024の余裕と最大出力4096トークンを先に予約する。SDKの再試行はしない。推論トークンを含むusageで精算する。usageがない・不整合・上限超過なら保守的な予約を残して止める。

日次上限は推定3,000円。料金・換算の前提は `packages/server/src/announcements/budget.ts`。同じMac上のこの評価コマンドについてプロジェクト別に集計するもので、他のMac・別のAPI利用の費用は含まない。実際の請求額を保証するものではない。
