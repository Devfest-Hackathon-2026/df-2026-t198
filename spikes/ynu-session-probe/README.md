# YNU LMSのログインの持ちを測る試作

確かめたいこと：Chrome拡張が裏から定期的にLMSを取りに行くとき、ログインがどれくらい保たれるか。

1. 定期的な取得で、ログインは延び続けるか（何もしないと1時間ほどで切れる、という見立て）
2. 延び続けるなら、上限（ログインしてから何時間で必ず切れるか）はあるか
3. PCのスリープや、ブラウザを閉じて開き直したあとも残るか
4. そもそも拡張機能からの取得に、ログインの状態（Cookie）が付くか

## 使い方

1. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にして、「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ。
2. いつもどおりYNU LMSにログインする。
3. 拡張機能のアイコンから「今すぐ確認」を押し、「ログイン中」と出るか見る。ログインしているのに「切れている」と出るなら、拡張機能からの取得にはログインの状態が付いていない（4がだめ）。
4. あとは放置する。既定は15分ごと。記録はアイコンの画面で見られ、「記録をコピー」で取り出せる。

保存するのは、時刻、HTTPの状態、最後に着いたURLのpath、ログアウトのリンクがあったかどうかだけ。画面の中身とURLのクエリ（セッションIDを含む）は保存しない。

ログインが保たれると分かったら、次は間隔を60分や90分にして、何もしないと何分で切れるかも測る。
