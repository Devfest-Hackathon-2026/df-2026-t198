# YNU LMSを開いたときに、裏で取得できるかを確かめる試作

製品では、本人がLMSを開いたときに、拡張機能が裏で全授業の課題を取りに行く（docs/decisions.md のD7）。その前提を確かめる。

1. **一番大事：** 拡張機能の裏からの取得に、ログインの状態（Cookie）が付くか。付かなければ、この方式は成り立たない
2. LMSのページを開いたことを、拡張機能が拾えるか
3. 参考：ログインはどれくらい持つか。PCのスリープやブラウザの再起動のあとも残るか。15分ごとにも取りに行って記録する

## 使い方

1. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にして、「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ。
2. いつもどおりYNU LMSにログインする。LMSのページを開くと、裏で1回取りに行く（10分に1回まで）。
3. 拡張機能のアイコンを押し、きっかけが `lms-page-opened` の行を見る。取り方が `worker`（拡張機能の裏）と `page`（開いているページの側）の2行が出る。`worker` が「ログイン中」なら1は成り立つ。`worker` が「切れている」で `page` が「ログイン中」なら、ページの側から取る方式に切り替える（docs/decisions.md のD8）。両方「切れている」なら、方式を見直す。
4. 「今すぐ確認」でも、その場で取りに行ける。あとは放置してよい。記録は「記録をコピー」で取り出せる。

保存するのは、時刻、きっかけ、HTTPの状態、最後に着いたURLのpath、ログアウトのリンクがあったかどうかだけ。画面の中身とURLのクエリ（セッションIDを含む）は保存しない。
