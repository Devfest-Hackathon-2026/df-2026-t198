# 画面の言葉の決まり（状態：案、2026-11-05）

学生の画面、支援担当の面談画面、LMSの隅の知らせ、カレンダーの予定に使う言葉の決まり。3つの試作（`design/prototypes/2026-11-05/`）の文言を見て、「根拠」などの言葉遣いを見直して作った。

## 決まり

1. **仕組みの言葉を画面に出さない。** 取得、記載、根拠、履歴、反映、基準のような、システムの側から見た言葉を使わない。その人に見えていること、することの言葉にする。
2. **状態は、変わったときと終わったときだけ書く。** すべての課題に「未提出」を付けない。出したものにだけ印を付ける。
3. **何もないときは何も書かない。** 「特記なし」「要確認 0件」を出さない。
4. **数を数える言葉は、まとめの1行だけに使う。** 例：LMSの隅の知らせ。一覧の中で「1件」を付けない。
5. **責める言い方、急かす言い方をしない。** 「期限切れ」「未達」「着手してください」を使わない。

## 「要確認」の使い方（2026-11-05、Sora）

「要確認」は使ってよい。文で書くときは「確認が必要です」でもよい（Sora）。

- 画面では、短い印「要確認」と、何と何が食い違っているかの1文を並べる。例：「要確認　お知らせでは21日(水)に延びたと書かれています」。印だけを出さない。
- 印の色は、警告の赤ではなく、目に留まるが責めない色にする。赤は、今日やらないと間に合わないものだけに使う（D12）。赤にしたい場合はD12と合わせて決め直す。
- カレンダーの予定名は、頭に「【要確認】」を付ける。両方の日付は説明欄に1行で書く。
- 確かめるものが無いときは、印も件数も出さない（上の3）。
