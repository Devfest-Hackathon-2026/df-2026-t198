# 画面の言葉の決まり（状態：案、2026-11-05）

学生の画面、支援担当の面談画面、LMSの隅の知らせ、カレンダーの予定に使う言葉の決まり。3つの試作（`design/prototypes/2026-11-05/`）の文言を見て、「根拠」などの言葉遣いを見直して作った。

## 決まり

1. **仕組みの言葉を画面に出さない。** 取得、記載、根拠、履歴、反映、基準のような、システムの側から見た言葉を使わない。その人に見えていること、することの言葉にする。
2. **状態は、変わったときと終わったときだけ書く。** すべての課題に「未提出」を付けない。出したものにだけ印を付ける。
3. **何もないときは何も書かない。** 「特記なし」「要確認 0件」を出さない。
4. **数を数える言葉は、まとめの1行だけに使う。** 例：LMSの隅の知らせ。一覧の中で「1件」を付けない。
5. **責める言い方、急かす言い方をしない。** 「期限切れ」「未達」「着手してください」を使わない。

## 「要確認」の使い方（2026-11-05、Sora）

「要確認」は使ってよい。文で書くときは「確認が必要です」でもよい（Sora）。

- 画面では、短い印「要確認」と、何と何が食い違っているかの1文を並べる。例：「要確認　お知らせでは21日(水)に延びたと書かれています」。印だけを出さない。
- 印の色は、警告の赤ではなく、目に留まるが責めない色にする。赤は、今日やらないと間に合わないものだけに使う（D12）。赤にしたい場合はD12と合わせて決め直す。
- カレンダーの予定名は、頭に「【要確認】」を付ける。両方の日付は説明欄に1行で書く。
- 確かめるものが無いときは、印も件数も出さない（上の3）。

## 準備から提出へ（Issue #141）

- 「次は提出」：準備が終わり、LMSで提出済みとまだ分かっていない課題の段。準備の「終わった」と提出の記録を分ける。
- 「LMSを開く」：メールと準備完了後の画面からLMSを開く。学生・面談画面の「LMSで見る ›」も同じリンク先を使う。
- 「道順」：詳細を直接開けないLMSでは「ホーム › 授業名 › 課題名」と書く。リンク先は定義のホーム。直接開けるLMSでは道順を足さない。
- 提出の確認：「提出済みかどうかは、次にLMSを開いたときに確かめます。提出済みと分かると「次は提出」から消えます。」と案内する。

## 紹介ページ（Issue #182）

- 「体験版を開く」：紹介ページ内の「体験する」へ進む。
- 「自分の大学で使う」：開発版のChrome拡張・Googleログイン・対応するLMSの案内へ進む。
- 「しくみ」：架空のHTML/CSSの図で、先生のお知らせ、LMSの締切変更、学生がLMSを開く、課題の読み取り、時間割・カレンダーの同じ予定の移動、支援担当の更新を順に見せる。章が見えた初回だけ再生し、最後で止まる。「もう一度見る」で再生する。動きを減らす設定では最後の状態を静止で出す（Issue #240）。
- 「共用の体験版」：紹介ページの主な入口を1つにする。設定のあるビルドでは「学生として試す」で体験用LMSへ入り、設定がないときは「体験用LMSを開く」を出す。審査向けの案内は補助の1行にする（Issue #240）。
- 「審査員の方」：説明資料の体験用アカウントを案内する。共用の組と審査の組を混同しない。
- ヒーローの時間割とメールは架空の固定日付の絵。操作できるボタンとしては読み上げない。「使う人」の画像は、エミュレーターで撮影した架空の授業の画面。両方の画像で同じ課題の締切変更を枠で示す。

## 共通部品と待ち時間（Issue #223）

- 共有の説明は「共有を許可した学生の授業と課題を出しています。」。許可は学生単位であり、授業ごとの選択があるようには書かない。
- 処理中の操作は、回転する印と「保存中…」「確認中…」などのラベルで示し、終わるまで再度押せないようにする。
- 3秒と10秒を過ぎたら、処理の内容と待機の状態を1行で示す。進んだ割合や完了時刻は推測しない。動きを減らす設定でも、状態を示す文字は出す。
- 共通部品の提出済みは既定で「出せました」、締切後は「締切を過ぎています」。普段の課題の行には「まだ」を足さない。締切を読めなかった状態と、締切の日付だけが分かる状態を区別する。
- 学生・面談ではLMSと準備の用語説明を繰り返さず、横スクロールは表の端の影で示す。

## 説明資料の審査用リンク（Issue #241）

- リンクで入る処理中は「ログイン中…」。終わるまで前の組の画面やログイン欄を出さない。
- 読めないリンク・ログインの失敗は「リンクでログインできませんでした。説明資料のアカウントで入ってください。」と、空のログイン欄を出す。リンクの中身や技術的なエラーは表示しない。
