# 大会の決まりと提出物

大会（DevFest GDGoC Japan Hackathon 2026）の公式資料から、開発と提出に効く決まりだけを抜き出す。確認日：2026-11-04（公式の参加者向け資料、運営の回答、提出資料のサンプル）。決まりが変わったら、確認した日を書き換える。

## 開発の決まり

| 項目 | 決まり |
|---|---|
| 期間 | 運営の開発開始の告知（2026-11-05 10:00）から、2026-11-10 19:00 のコードフリーズ・提出締切まで |
| 開始前のコード | 開始前に書いた・生成したコード（PoCを含む）を提出物に入れない。開始後にゼロから書く |
| 実行基盤 | App Engine、Compute Engine、GKE、Cloud Run、Firebase App Hosting、Firebase Hosting のうち1つ以上で動かす。今回は Cloud Run と Firebase Hosting |
| 主な技術 | プロダクトの主な技術はGoogleの技術にする。他社のLLMを内部で使うことは禁止されていないが、Googleの技術の活用としては数えられない |
| 発表 | デモとピッチで他社の製品を前に出さない。他社のAIツールが主のものは審査の対象外 |
| AIの開発支援 | AIのコーディング支援は使ってよい。使った場面・使い方・理由を記録する（[ai-usage.md](ai-usage.md)） |
| カテゴリ | 医療・福祉、観光、教育、エンターテインメント、クリエイティブのどれか。今回は教育 |
| 選んだ理由 | テーマ「Own the Why, Build with Intent.」。案を比べ、選んだ理由と採用しなかった案を残す（[decisions.md](decisions.md)） |
| 秘密の情報 | APIキーなどをcommitしない |

## 提出物

| 提出物 | 中身 | 今の置き場所・PLAN.md |
|---|---|---|
| GitHubのrepo | 提出用repo（公開）。コードフリーズのあとは読み取り専用 | C36 |
| プロダクトの説明資料 | 公式のテンプレートに沿う。下の表 | 未着手 |
| デモ動画 | オンライン会場は、デモを含む発表の動画。偽装した動画は審査の対象外 | 未着手 |
| 著作物利用シート | 素材、ライブラリ、データの出典とライセンス | [third-party.md](third-party.md) から作る |
| ピッチのスライド | 現地会場に申し込んだチームは提出する | 未着手 |
| デプロイ先のURL | 2026-11-14 まで動かし続ける | C14、C31 |

- 会場ごとのGoogleフォームに、GitHubのURLと、提出資料を入れたGoogleドライブのフォルダのURLを出す。フォルダは「リンクを知っている全員が閲覧可」にする。閲覧できない提出は審査されない。
- 必須の項目が足りない、カテゴリの外、指定の実行基盤を使っていない、といったものは審査の対象外になり得る。

## 説明資料の項目（公式のサンプルから）

| 区分 | 項目 |
|---|---|
| 冒頭 | 会場、チーム名、メンバー、アプリ名、カテゴリ、GitHubのURL |
| 必須 | 1. プロジェクトの概要／2. 解決する課題（対象の利用者、課題と根拠、既存の方法との違い）／3. Googleの技術の活用（実行基盤の選択と使った箇所、選んだ理由、良い点と悪い点）／4. アーキテクチャ図／5. デプロイ先のURL |
| 任意 | 6. 動作の確かめ方／7. アプリの詳細や機能の自由記述 |
| 採点の外だが必須 | 8. AIを使った場面・使い方・理由／9. 開発で得たもの・成長 |

- 任意の6には、審査する人が動作を確かめる手順と試す入力を書く（C33の試す人のアカウントと、C34の筋書き）。個人のパスワードやAPIキーは書かない。
- サンプルの例文を実績として流用しない。

## PLAN.mdに足す候補

提出物のうち、PLAN.mdの完成条件に無いもの。足すには2人の合意が要る（PLAN.mdの「数え方」）。

| 候補 | 確かめ方 |
|---|---|
| 説明資料を公式のテンプレートの項目どおりに書き、Googleドライブのフォルダに置く | 項目1〜9がそろい、ログインしていないブラウザでフォルダが開ける |
| デモ動画を撮り、同じフォルダに置く | 実際の操作を撮ったもので、筋書き（C34）が映っている |
| 著作物利用シートを作る | `third-party.md` の全行がシートにある |
| デプロイ先を 2026-11-14 まで動かす | 11/14に、試す人のアカウントで筋書きが通る |
| （現地会場なら）ピッチのスライド | 提出の締切までにフォルダにある |
