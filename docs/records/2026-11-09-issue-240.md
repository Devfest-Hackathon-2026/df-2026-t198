## 製品画像の撮影

`packages/web/tests/capture-landing-shots.mjs` が、標準の架空データをエミュレーターに作り、LMSを開く→学生と支援担当でログイン→先生が締切を1日延ばす→LMSを開く、の順に操作する。学生の課題欄で旧11/12 17:00と新11/13 17:00・打ち消し線・強調を確認し、同じ課題を支援担当の変化の欄でも確認して撮った。学生は1280×1100、支援担当は800×1100。画像はページ全体ではなく、時間割と変化の欄をそれぞれ切り出した。

囲みは撮影ページにだけ一時的に付け、製品のCSSは変更していない。[撮影結果](2026-11-09-issue-240/capture-results.json)に、寸法、架空の時刻、囲んだ文字、SHA-256を記録。格納した画像との一致も確認した。ブラウザの時刻は同日のサーバーの変更時刻より後に固定し、サーバーの記録を「未来」として除外しないようにした。保存された変更の日時は書き換えていない。

再実行する入口（`PLAYWRIGHT_MODULE` はローカルのPlaywrightを指す）：

```sh
pnpm exec node scripts/run-emulators.mjs --config-from-env --project demo-kadai-hisho --only auth,firestore "node packages/web/tests/run-landing-browser.mjs --capture"
```

紹介ページの検査は同じrunnerの `--layout`・`--flow`・`--dialogs`・`--shared`。`--dialogs` は章送りのブラウザ試験も含む。分割して同じエミュレーターで実行するときは、上記のとおり `KADAI_DEMO_PASSWORD` を共通の一時値として環境から渡す。
