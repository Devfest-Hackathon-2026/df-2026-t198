# Issue #120 作業計画

対象は学生のLMS操作と拡張の取得の衝突。学生が押した操作を1回だけ通し、拡張から返事が来なくても15秒以内に解放する。実物の入力、SID、Cookieは記録しない。

- `packages/extension/src/student-navigation.ts` と `content.ts`：ホームで2秒操作がないときだけ取得を申し出る。取得中のクリック・送信・Enterを受け止め、返答・拒否・例外・15秒の期限で必ず再開する。pagehideでは取得を中止する。
- `collection-worker.ts` と取得の補助：両経路で同じ排他を使う。譲渡後の新規通信を止め、進行中の通信の終了後にホームへ戻す。ページが既に移った場合や期限内に通信が終わらない場合は、遅い復帰通信を出さず取得を捨てる。
- `lms-definitions/coursepower/navigation.json`：状態保持・ホームのパス・復帰先・エラー画面の判別を宣言する。読み取り定義と見本の正解は変更しない。
- `collection.ts`、診断・表示：エラー画面では再試行・経路切替・残りの授業を止める。`yielded` は失敗・10分待機・警告アイコンの対象にしない。診断は固定コードと件数だけ。
- 試験：既存の偽LMSに画面状態を加え、修正前にエラー画面の打ち切りの失敗を確認する。取得中の学生の移動、取得終了後の移動、ページ側経路、ホーム以外・2秒未満の拒否、返事なし・同期例外・複数操作・Enter・送信を試験する。Chromiumで実際のクリック・フォーム・Enterも通す。

検査は `pnpm typecheck && pnpm lint && pnpm test && pnpm build && pnpm progress --check && pnpm check:samples` とM1。C04・C05の実機確認はmerge後のSoraの操作なので、今回の偽LMSの結果だけで `[x]` にしない。PLANには証拠を追記する。依存・クラウド資源・LMSへの自動提出は追加しない。実物の形と合わない点は学生の操作を通して取得をやめ、PRに残す。
