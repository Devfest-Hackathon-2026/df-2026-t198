# 学生画面と面談画面の読みやすさ（Issue #272）：検証記録

branch `issue-272-ui-polish`。PR #280 の head の上に積んだ。依存・API・データの形・拡張・server・紹介ページは変更していない。画像は体験用の架空データ（ローカルのエミュレーター）だけ。

## 変えたこと

1. 学生の時間割のマスの締切を日付だけにした。時刻はマスの読み上げ（`aria-description`）と授業の詳細に残した。授業名は行の長さをそろえて折り返す（`text-wrap: balance`）。
2. 学生の「今週の締切」と授業の課題に「締切が変わった」の札を付けた。
3. 準備の操作を、主ボタン「終わった」・普通のボタン「後回し」・文字「外す」にした。
4. 今週の締切が無いときに「今週の締切はありません」を出す。
5. 面談「相談する」の保存済みの準備を黄色（`#ffe14d`）で塗った。文字は `#18202e` で、コントラスト比は約 12.5:1。
6. 保存後の「準備の予定を入れました。」を、入れたマスの中に出す。
