# Issue #162の確認（2026-11-08）

専用Gmailのsender、本人だけの通知設定APIと学生画面、orange向けの準備手順、D36案を追加した。Cloudの設定・secret登録・デプロイ・実送信は実行していない。

## 満たした操作

- 固定From・本人To 1件、CC/BCCなし。OAuth更新とGmail送信を標準fetchで接続。401・403・429・5xx・応答喪失・送信元の失効を偽APIで区別し、送信POSTを再送しない。
- 本人が有効化・停止・再読取できる。他人のUID・宛先・移行状態の指定を拒否。支援担当の共有許可を通知の権限に使わない。体験用アカウントは実通知を設定できない。
- 送信元未準備・認可切れ・本人宛先不明・切替前は有効化できない。停止は送信元が使えなくても保存できる。設定保存でAPI受理日時を作らない。
- 二重押し、同じ保存の同時再送、古い版の拒否、通信失敗、再訪、アカウント切替を確認。受理・失敗・結果不明・認可切れを表示し、過去の受理日時と受信箱への到着を混同しない。
- 旧拡張からの切替を設定APIで行わず、deliveryOwner/migrationStateの既存条件を維持した。
