## Argon

`agy --model gemini-4-argon-high --mode plan` に変更文言だけを渡し、日本語・主体の曖昧さを点検した。比喩・誇張・標語・新しい機能の約束は足さないよう指定した。

| 指摘 | 採否 |
|---|---|
| 「共有を許可した支援担当」は許可する主体が曖昧 | 採用。「学生が共有を許可していれば、支援担当の画面にも変更が表示されます。」とした。 |
| 「カレンダーと時間割の締切」は誰の画面か曖昧 | 採用。「学生のカレンダーと時間割で、締切が11/12から11/13に移ります。」とした。 |
| 「締切の変化を読み取り」は対象が曖昧 | 採用。「変更後の締切を読み取り」にした。 |
| 図の「拡張」を「拡張機能」に揃える | 採用。 |
| 「締切が変わった」を名詞形に揃える | 不採用。Issue指定の印であり、起きたことを表す自然な状態表示のまま残した。 |

見出しと本文の候補はPR本文に置く。表示中の案を最終的な言葉の選択とは扱わない。
