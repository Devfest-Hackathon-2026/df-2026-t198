## 画面

- 今の段に主ボタンを1つ置き、補助の操作を文字のリンクにした。狭い画面でも4段を縦に並べる。
- LMSは大学のポータルを思わせる帯・メニュー・罫線の一覧にした。読み取りのセレクタを残し、延長後だけ変更の説明と変更前の締切を出す。やり直すと変更前の表示も初期化する。
- メールは黄色い見本の帯、差出人、本文の準備のカードで表示する。メールを開くと体験の窓を隠し、確認を開くとメール本文を隠す。「体験に戻る」「メールの見本に戻る」で戻れる。
- 確認のカードは、押す前の主ボタン1つ、完了後の「次は提出」のLMSリンク1つを強調する。準備の完了と提出を分ける。直接リンクでもカードの幅を確保し、周囲の主ボタンを文字の操作にする。
