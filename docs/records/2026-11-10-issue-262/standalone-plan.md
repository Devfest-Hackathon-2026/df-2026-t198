# 録画用映像の分離

PR #266のSoraの方針と今回の依頼を正本とする。初めてToDokuを見る人が締切変更から面談・朝のメールまでを追え、Soraが75秒のデモに挿入できる25秒の素材を録画できるようにする。人物・授業・日付は既存の架空のものだけを使う。

1. `mechanism.tsx`・`mechanism-scene.tsx`・`mechanism.css`、紹介ページの試験、`docs/ui-words.md`、`scripts/record-mechanism.mjs`をorigin/mainへ戻す。紹介ページから映像の参照をなくし、色は既存の共通トークンに保ち、適用先を映像ページへ限定する。
2. `story/player.tsx`・`player.css`と`app.tsx`に単独の `/slides/story` を用意。`autoplay=1` と `sound=1` を維持し、`short=1`は5場面25秒（切り替え込み）、通常は7場面32.4秒。データ形・API・依存は変えない。
3. 要件から単体試験と`story.browser.mjs`を追加。1280×720、通常/短縮の全場面、最初から最後までの自動再生、操作・音・静止一覧、紹介ページとの分離を直接確かめる。今回は範囲が明確な分離と追加なので実装後の直接検証を使う。
4. `scripts/record-story.mjs`で音を含む両版を`out/issue-262/story.mp4`と`story-short.mp4`へ保存。画像と録画のフレーム、寸法・長さ・音声を確認する。旧記録は過去の状態として残し、新しい確認は別の記録に書く。
5. 指定6検査、画面QA、M6、public-demoと紹介ページ試験をJST/UTCで実行。既存プロセスを止めず、エミュレーターのポートが空くまで待つ。C38は全体動画の提出まで未完了のまま。PLANの証拠だけを更新し数字を再計算する。
