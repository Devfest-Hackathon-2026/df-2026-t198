## 変更と確認

| 操作 | 確認した結果 |
| --- | --- |
| 学生・支援担当が準備の一覧を見る | 日付・開始時刻順。同名の課題も日時で区別。390pxでは日時・時限・状態・操作を縦に並べ、ボタンが画面内に収まる |
| 面談で候補の「入れる」を押す | 入力へフォーカスとスクロール。YNU・体験用の1限は08:50〜10:20。PandAの時刻は補わない |
| 時限をはみ出す時刻を入れる | 設定表の時刻と、時限・時刻を確かめる案内が出る。コマの中で短い準備時間にすることは認める |
| 保存する | フォームが閉じても面談画面に「入れました」が残り、開いた学生画面にも予定が出る |
| 学生が自分の面談を開く | 学生選び直しのリンクを出さず、本人に向けた案内を出す |
| 追加→取消、メールの完了→LMSの締切延長 | 前の操作の知らせを消し、最新の知らせだけを出す |
| 締切のカレンダーを見る | 提出済みは「出せました」と破線。黄色の説明、横スクロールの案内、日付への移動と「今日へ」が使える |
