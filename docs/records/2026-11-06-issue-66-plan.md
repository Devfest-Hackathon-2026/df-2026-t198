# Issue #66 の実装計画

読者は体験用アカウントで試す学生・支援担当。先生役で締切を延ばし、LMSを開くと、開いたままの画面で札が翌日に移ることと締切の変化に気づけるようにする。仕様はIssue #66と指定のFable見直しの優先1・2・3・9。

- `demo-calendar.tsx`：保存済み予定だけを今日（日本時間）から7日に並べ、範囲外を下にまとめる。学生画面の上部に置き、実アカウントの締切一覧は残す。
- `student.tsx`：授業マス・開いた課題の締切を8秒強調。最終成功から72時間以上なら日付とLMSを開く案内を出す。
- 共通の強調部品とログイン案内部品を追加。`session-page.tsx`は締切表示とログイン案内の接続だけ、`app.tsx`はナビの順・名前だけを変える。`styles.css`に帯・強調・狭い幅の指定を加える。
- 単体試験で日本時間の日付境界、7列、範囲外、時刻を補わない表示、72時間の境界を確認。既存M6の8操作は維持し、ブラウザ試験に札の移動・強調の開始と終了・初回非強調・各ログイン入口・390pxの横スクロール・古い情報の案内を追加する。
- 変更前にM6と画面写真を保存。変更後に `pnpm typecheck && pnpm lint && pnpm test && pnpm build && pnpm progress --check && pnpm check:samples` と `pnpm metrics:m6` を実行し、1280px・390pxを直接見る。既存の承認済み仕様の実装なのでdirect-to-verificationで進める。
- 依存・API・データ形・見本の正解は変えない。変更が必要なら停止。実LMS、公開先へのデプロイ、Googleカレンダーは対象外。画面写真の好みの判断はSora、別系統のレビューとmergeはClaudeに残す。
