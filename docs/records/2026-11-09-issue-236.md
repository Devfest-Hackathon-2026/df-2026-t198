# Issue #236：紹介ページの章送り

2026-11-09。PR #239。紹介ページの章送りと回帰試験の確認記録。

## 変更と判断

- 章送りは `requestAnimationFrame` と sine の ease-in-out。距離1pxあたり1ms、最短600ms・最長1000ms。各フレームの `scrollTo` は `instant` を明示し、CSSのsmoothと重ねない。
- 目次・章末のリンクにも同じ動きを使う。hashを履歴に残し、章へフォーカスを移す。一時的なtabindexはフォーカスが外れた時か後始末で取り除く。
- 指やスクロール用のキーを離すまで送らない。scrollendと150msの静止判定の両方で入力の終了を確認する。
- 移動中のホイール・タッチ・キー・ポインターで止め、中断した操作の続きでは再開しない。戻る操作と後始末でも止める。
- 拡大表示の入力は除外し、closeで入力状態を戻す。reduced motionは送る直前と各フレームで確認する。
- 章の座標判定と12%の基準は変更していない。見た目・文言・依存・データ契約の変更はない。
