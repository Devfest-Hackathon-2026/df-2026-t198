# Issue #141：メールの見出しと準備後の提出案内

## 変更と範囲

- メールを授業名・課題名の見出し、準備時刻、締切、従来のボタンの順にした。宛名は付けず、HTML・textとも注記は各メールの末尾に1回だけ置く。48時間以内の締切も同じ見出しを使う。
- 準備が終わり、未提出・取消/終了以外・締切前の課題を「次は提出」に締切順で出す。課題ごとに重複を省き、提出操作のボタンは付けない。準備の完了リンクの画面も現在の台帳を読み、提出済みになれば案内が消える。
- メール・学生・面談画面は同じ `assignmentLmsLink` を使う。`statefulSession: true` の定義では同じoriginの `home` と道順、それ以外は詳細のリンクを返す。課題とホーム両方のURLの安全検査を維持する。
- 保存型・Firestore規則・依存・取得部品・拡張の送信方式は変更しない。応答の追加項目と理由は [D33](../decisions.md#d33-準備後に提出先を案内する2026-11-07issue-141)。サーバーへの同梱に必要な `.gcloudignore` の追加は定義JSON1個だけ。`gcloud meta list-files-for-upload` でもLMS定義の対象が `coursepower/navigation.json` だけであることを確認した。
