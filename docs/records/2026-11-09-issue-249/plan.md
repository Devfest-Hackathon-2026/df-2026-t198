# Issue #249 作業計画

学生は時間割全体を見て授業を選び、詳細で課題を確認する。一般の学生には面談の入口を出さず、体験用LMSでは公開体験と説明資料のアカウントを分ける。

- `features/student/page.tsx`・`student.css`：固定高の行、2行までの授業名、全文のtitleと読み上げ名、1行の締切。同一コマの複数授業も同じ行高に収め、授業色と詳細操作を維持する。
- `shared/auth/session-access.ts`・`app.tsx`：既存の共有許可・体験プロフィール・担当学生APIで入口を判定する。未確認・ログアウト・利用者変更では面談を出さない。`features/session` は変更しない。
- `features/demo/page.tsx`・`demo.css`・`shared/auth/public-demo-entry.tsx`：公開体験を上に置き、審査用ログインを閉じたdetailsに入れる。設定なしの案内を出す。審査リンク失敗時は回復用の欄を開く。
- 単体試験・`tests/student-fit.browser.mjs`：長い架空授業名、英語付き、同一コマ2授業、平日5限／週末7限、1280×800・390×844、共有の有無・取消・体験学生・支援担当、入口の設定あり／なしと審査リンクを確認する。
- 指定6検査、審査QA 28/28、M6 8/8、公開体験・学生・関連ブラウザ試験を実行。変更前後画像と結果をこのフォルダに保存する。既存の正解見本と指標の合格基準は変えない。
- 文言は共通資料、kuchiguse、yomiyasu、Argonで点検し、指摘と採否をPRに残す。`docs/ui-words.md` と既存C18の証拠を更新する。

紹介ページ・server・実物データ・依存・保存形式・規則・APIは変更しない。共有の判定が既存データでできない場合は停止。エミュレーターポート使用中は待機。変更前のブラウザ試験で行高・画面内への収まりの失敗を確認してから実装する。merge・デプロイは行わない。
