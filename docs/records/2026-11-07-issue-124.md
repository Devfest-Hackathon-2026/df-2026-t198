# Issue #124 画面の言葉の点検（2026-11-07）

学生と支援担当が、準備の予定・課題・更新の状態を読み分けられるよう、`docs/ui-words.md` とD13に照らして点検した。文言と初期状態の表示だけを変更し、データ・API・権限・予定を動かす条件・メールの送信条件は変更していない。手入力の課題と、設定画面の開発者用接続診断は対象外。

## 変更一覧

| 場所 | 変更前 | 変更後・理由 |
|---|---|---|
| 学生・面談の古い情報の帯 | 最後にLMSから取ったのは○/○です | ○/○から更新がありません。「取った」を利用者に見える状態にする |
| 学生・面談の失敗の帯 | 一部の課題を確認できていません／今回すべての課題を確認できませんでした | 課題をすべて確認できていません。全件を確認できていないという条件をそろえる |
| 準備一覧・詳細・前回の約束 | まだ | 初期状態は書かない。終わった・後回しにした場合だけ状態を添える |
| 準備一覧の読み上げ名 | 準備予定の一覧 | 準備の予定の一覧。詳細画面や見出しと呼び方をそろえる |
| 準備を入れられない結果 | この予定は入れられませんでした | この準備の予定は入れられませんでした。課題との違いを明示する |
| 準備を外せたか不明の結果 | 取消を確認できませんでした | 準備の予定を外せたか確認できませんでした。押した操作と同じ言葉にする |
| 完了の結果・メールのリンク先 | 準備を「終わった」にしました | 準備が終わりました。LMSへの提出は別に行ってください。提出との区別は維持する |
| 後回しの結果・メールのリンク先 | 次の空いたコマに動かしました。カレンダーの更新は接続中の拡張機能で行います | 準備の予定を次の空いたコマに動かしました。カレンダーの予定は、拡張機能がGoogleにつながると動きます。対象と更新待ちの条件を残す |
| 動かせない結果 | 予定を動かしませんでした | 準備の予定を動かしませんでした。対象をそろえる |
| メール本文（HTML・テキスト共通） | 「終わった」は準備の記録です | 「終わった」は準備が終わったときに押してください。利用者がする操作で説明する。LMSへの提出は別という注意は残す |
| 体験用メールの見本 | 今朝のメール／本人に届くメールの見本です | 今日やることのメール／今日の準備と締切の近い課題を知らせるメールの見本です。設定画面と呼び方をそろえる |
| 拡張のアイコン・ポップアップ | LMSの課題を確かめています／確かめました／確かめられませんでした | 更新しています／更新しました／更新できませんでした。更新と人による内容確認を読み分ける |
| Gmailの設定 | 入れると…読む権限…切ると… | チェックを入れると…メールを読む許可…チェックを外すと…。操作と許可の対象を明確にする |
| Gmailの許可エラー | 切り替えを入れ直してください | 「毎朝、今日やることをGmailで受け取る」を入れ直してください。どの設定を操作するかを明示する |

メール件名の「今日やること（日付）」「時刻から：課題名の準備」は、日付・開始時刻・課題名と、朝のまとめ／予定前の知らせを読み分けられるため維持した。予定の登録者表示、学生による取消、空きコマと個人の予定の区別も維持した。

## 確認

- 6検査：`pnpm typecheck && pnpm lint && pnpm test && pnpm build && pnpm progress --check && pnpm check:samples`。すべて終了コード0（7時台）。
- 実物のLMS・Google・Gmailは使わず、架空のデータとローカルのAuth・Firestore、偽Chrome APIで確認する。依存の追加はない。
- 通常のエミュレーターポートは別作業が使用中だったため、6検査では一時的にFirestore 8124へ変更し、検査後に `firebase.json` を元の内容へ戻す。ブラウザ試験には `/tmp` の設定でFirestore 8125・Auth 9125を使う。
- 各ブラウザrunnerは空のエミュレーターで個別に実行する。連続実行時に既存アカウントと新しい試験用パスワードが一致しなかったため、試験の入力や実装を変えず、エミュレーターを起動し直した。
- M6：比較元は `PLAN.md` のローカル8/8（2026-11-06）。今回は未測定。Issue #124の指定は日本時間9時以降であり、今回の作業時点は7時台。M6で使う帯の待機文だけを更新し、筋書き・時計・合否の判定は変えていない。9時以降に `PLAYWRIGHT_MODULE=<既存のPlaywrightの入口> pnpm metrics:m6` の再測定が残る。
- その他のM指標：取得精度、解析、速度、カレンダー同期の実装は変えないため対象外。言葉の自然さの人による評価は未測定で、改善したという数値の主張はしない。
- 完成条件：新しく満たしたC番号はない。すでに `[x]` のC20（学生の更新の帯）・C22（ポップアップ）・C23/C24（面談・準備の予定）に今回の証拠を追記する。C34のM6は今回の完了扱いにしない。
