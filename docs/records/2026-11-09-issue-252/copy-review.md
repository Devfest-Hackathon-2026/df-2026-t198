# 面談画面の文言点検

`agy --model gemini-4-argon-high --mode plan -p` で、新しいラベルと状態表示だけを渡し、不自然な日本語と修正案を確認した。実データ・ログイン情報・画面全体は渡していない。

| Argonの指摘 | 採否と理由 |
|---|---|
| 「確かめる／相談する」を名詞の「確認／相談」にする | 不採用。画面を切り替える操作であり、Sora指定の名前を保つ。 |
| 「情報の取得時点」を「取得日時」にする | 不採用。Sora指定のカード名を保つ。複数の接続先それぞれの成功時点を示す。 |
| 「該当する締切なし」を「締切なし」にする | 不採用。次回面談までの期間に該当しないだけで、課題自体に締切がないとは限らない。 |
| 次回／前回の未設定表示をそろえ、「前回」に「面談」を補う | 「前回の面談日時未設定」を採用。次回は入力を促す状態の文として「次の面談日時が未設定です。」を維持。 |
| 「締切が変わった／出せました」を名詞または敬体に統一 | 不採用。既存の共通部品と文言規約にある状態名を維持。 |
| 件数の前の空白をそろえる | 不採用。「準備の候補」と件数はラベルと値を区切る表示。情報の意味は変えない。 |

kuchiguseの型の表で標語・比喩・対句・重複説明がないことを確認。yomiyasuでラベル一覧を点検し、最終稿の候補0件。前回の面談日時の明示以外は変更せず、件数・期間・未設定の意味を読み比べた。

```text
yomiyasu-check: executed via=verify run=20261109T081911Z-1115d9c2 attempt=1 final=sha256:9a69cf67bcad mode=rewrite checks=lint,diff meaning_risk=0 replay=skipped
```

機械検査は文意の正しさや人の承認の証明にはならない。画面の好みとClaudeの別系統の見直しはPRで確認する。
